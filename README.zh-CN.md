# dx7toFM1

[English](README.md) · **简体中文**

把 Yamaha DX7 的 32 音色整合包（`.syx`）拆成一个个独立的单音色 `.syx` 文件，
文件名直接使用音色名 —— 拆完就可以逐个导入 FM1 的第三方固件。

---

## 为什么需要这个项目

FM1 可以演奏 DX7 的音色，但**导入时必须一份文件一个音色**：FM1 的**第三方固件**不认
整合包，只能逐个导入单音色。而网上能下载到的 DX7 音色（原厂 ROM 卡带、用户自制音色包、
各种合集）基本都是**32 个音色打包在一个文件里**的整合包，固件没法直接用：

| | DX7 32 音色整合包 | DX7 单音色 |
|---|---|---|
| 文件头 | `F0 43 0n 09 20 00` | `F0 43 0n 00 01 1B` |
| 数据 | 4096 字节，每音色 128 字节，**打包（packed）** | 155 字节，**非打包（unpacked）** |
| 文件大小 | 4104 字节 | 163 字节 |
| FM1 第三方固件 | ❌ 无法导入 | ✅ 可以逐个导入 |

两种格式不只是长度不同：整合包里每个音色的参数被「压缩」进 128 字节，几个参数共用同一
个字节的位；而单音色文件是 155 字节，一个参数一个字节。所以要先用位运算把音色**展开**，
再重新封成单音色的 SysEx 消息 —— 这就是本工具做的事，一次处理整包 32 个音色。

## 去哪儿下载 DX7 音色库

DX7 原厂音色合集（ROM 卡带等）可以在这里下载：

**<https://yamahablackboxes.com/collection/yamaha-dx7-synthesizer/patches/>**

下载任意一个 `.syx` 整合包，用 `dx7toFM1.py` 跑一遍，就能得到一个装满单音色文件的文件夹。

## 环境要求

Python 3.8 及以上。只用标准库，不需要 `pip install` 任何东西。

## 快速开始

```bash
python3 dx7toFM1.py rom1a.syx
```

```
rom1a.syx — split: 32 voice(s)
  01  'BRASS   1'    -> BRASS 1.syx
  02  'BRASS   2'    -> BRASS 2.syx
  03  'BRASS   3'    -> BRASS 3.syx
  ...
  32  'TAKE OFF'     -> TAKE OFF.syx

Total: 32 voice(s).
```

`rom1a_voices/` 里的每个文件都是合法的 163 字节 DX7 单音色，FM1 的第三方固件可以直接导入。
文件名就是整合包内部存的音色名。

## 用法

```bash
python3 dx7toFM1.py <整合包.syx> [<另一个.syx> ...] [选项]
```

| 选项 | 说明 |
|---|---|
| `-o, --out DIR` | 输出目录（默认 `<输入文件名>_voices`） |
| `-n, --numbered` | 文件名前加两位序号：`01_BRASS 1.syx` |
| `-p, --prefix STR` | 给所有文件名加统一前缀 |
| `-u, --underscore` | 音色名里的空格换成下划线：`BRASS_1.syx` |
| `-l, --list` | 只列出音色名，不写文件 |
| `-q, --quiet` | 不打印逐个音色的明细 |
| `--selftest` | 跑一遍打包/解包回环自检后退出 |

例子：

```bash
# 默认输出到 ./rom1a_voices/BRASS 1.syx ...
python3 dx7toFM1.py rom1a.syx

# 加序号 + 下划线，输出到指定目录
python3 dx7toFM1.py rom1a.syx -o voices -n -u

# 批量拆一整个文件夹里的整合包（每个包一个子目录）
python3 dx7toFM1.py *.syx -o voices

# 只想看看包里都有什么音色
python3 dx7toFM1.py rom1a.syx --list
```

## 输出格式

写出的每个文件都是标准 DX7 单音色 dump：

```
F0 43 0n 00 01 1B | 155 字节非打包音色数据 | 校验和 | F7
```

- 校验和是 Yamaha 标准的 7 位校验和：`(-sum) & 0x7F`。
- 设备号/通道号 `0n` 沿用源整合包里的值。
- 音色名取自整合包内部存的 10 个字符。

文件名规则：

- 去掉尾部的补位空格（`BRASS   1` → `BRASS 1`），中间的空格保留。
- 文件名非法字符（`/ \ : * ? " < > |`）替换成 `_`。
- 重名自动加后缀：`BRASS 1.syx`、`BRASS 1-2.syx`……
- 名字全空的音色退化为 `voice_01`、`voice_02`……

## 原理

**整合包消息**（4104 字节）：

```
F0 43 0n 09 20 00 | 4096 字节数据 | 校验和 | F7
                     32 个音色 × 128 字节，打包格式
```

**打包音色**（128 字节）—— 6 个算子各 17 字节，然后是全局参数和音色名：

| 字节 | 内容 |
|---|---|
| 0–16 | OP6（算子 6） |
| 17–33 | OP5 |
| 34–50 | OP4 |
| 51–67 | OP3 |
| 68–84 | OP2 |
| 85–101 | OP1 |
| 102–109 | 音高 EG 的 rate 1–4、level 1–4 |
| 110 | 算法（0–31） |
| 111 | bit3 振荡器键同步、bit2–0 反馈 |
| 112–115 | LFO 速度、延迟、音高调制深度、幅度调制深度 |
| 116 | bit6–4 音高调制灵敏度、bit3–1 LFO 波形、bit0 LFO 键同步 |
| 117 | 移调（0–48，24 = 中央） |
| 118–127 | 音色名，10 个 ASCII 字符 |

**打包算子**（17 字节）—— 挤得最狠的部分，多个参数共用字节：

| 字节 | 内容 |
|---|---|
| 0–3 | EG rate 1–4（0–99） |
| 4–7 | EG level 1–4（0–99） |
| 8 | 键盘电平缩放断点 |
| 9 | 左侧深度 |
| 10 | 右侧深度 |
| 11 | bit3–2 右曲线、bit1–0 左曲线（0–3） |
| 12 | bit6–3 失谐（0–14）、bit2–0 速率缩放（0–7） |
| 13 | bit4–2 键速灵敏度（0–7）、bit1–0 幅调灵敏度（0–3） |
| 14 | 算子输出电平（0–99） |
| 15 | bit5–1 频率粗调（0–31）、bit0 振荡器模式 |
| 16 | 频率细调（0–99） |

**非打包单音色**（155 字节）—— 一个参数一个字节：

| 字节 | 内容 |
|---|---|
| 0–20、21–41 …… 105–125 | OP6 …… OP1，各 21 字节 |
| 126–133 | 音高 EG 的 rate 1–4、level 1–4 |
| 134 | 算法 |
| 135 | 反馈 |
| 136 | 振荡器键同步 |
| 137–140 | LFO 速度、延迟、音高调制深度、幅度调制深度 |
| 141 | LFO 键同步 |
| 142 | LFO 波形 |
| 143 | 音高调制灵敏度 |
| 144 | 移调 |
| 145–154 | 音色名 |

工具里实现了双向函数（`unpack_voice()` / `pack_voice()`），并用逆函数做自检。

## 验证

- `rom1a.syx` 全部 32 个音色：`pack(unpack(voice))` 能逐字节还原原始的 128 字节，
  说明位域没有丢位、没有错位。
- 把 `tine-ep.syx`（一个已知正常的单音色文件）丢进工具走一遍，输出与原文件逐字节相同，
  连校验和都一样。
- 从 `rom1a.syx` 还原出的音色名与官方 ROM1A 音色表完全一致。
- `python3 dx7toFM1.py --selftest` 会跑 2000 组随机音色的打包/解包回环。

## 说明与限制

- 只做单向拆分：把整合包拆成单音色，不支持把单音色重新合并成 32 音色整合包。
- 输入本来就是单音色也能处理，会重新封装并按音色名另存，而不是原样复制。
- 一个文件里前后拼了多个整合包，也能全部拆出来。
- 校验和不对只报警告，不会中断转换。
